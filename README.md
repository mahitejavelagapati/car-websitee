# NOCTIS // Unbadged Electric Grand Tourer

> A fictional, unbadged, low-slung electric grand tourer coupe in matte graphite grey. Sculpted in darkness. Powered by pure light.

![NOCTIS Reference](carr%20imageeeeee.png)

## Overview
**NOCTIS** is a high-performance interactive automotive digital experience built from a generative AI creative pipeline (ChatGPT, Google Flow, and Google Antigravity).

- **Finish:** Matte Graphite Grey (`#222428`) on carbon-titanium monocoque.
- **Lighting Signature:** Continuous 6500K cool-white front laser lightbar & continuous 620nm deep-red rear lightbar.
- **Chassis Architecture:** 800V silicon-carbide solid-state skateboard (120 kWh, 780 km range).
- **Powertrain:** Dual permanent magnet synchronous motors delivering 1,120 kW (1,500 hp) and 1,400 Nm of torque.
- **Performance:** 0–100 km/h in 1.98s | Top Speed 340 km/h | 0.19 Cd.

## Features
- **Dual-Mode Cinematic Stage:**
  - **Frame Scrubber:** High-performance canvas-based 60fps scrubbing with 200 extracted high-res frames per chapter.
  - **4K Film Mode:** Seamless continuous playback cycling through cinematic motion transitions (`Clip 1` → `Clip 2` → `Clip 3`).
- **Telemetry HUD:** Real-time speed, torque, surface condition, optical metadata, and active lightbar status.
- **Deconstruction Studio:** 4D disassembly scrubber (0% Assembled → 100% Exploded) with draggable split curtain and interactive engineering radar hotspots.
- **Step 0 Design Lock Simulator:** Lighting simulation controls (Studio Soft, Rim Light Emphasis, Lightbars Only, Monochrome).
- **Procedural Audio Synthesizer:** Built using the HTML5 Web Audio API to procedurally generate a 52Hz ambient sub-bass drone and motor acceleration harmonics.

## Quick Start
Open `index.html` in any modern web browser or start a local server:

```bash
# Python local server
python -m http.server 8000
```
Then navigate to `http://localhost:8000`.
